# دليل التحقق من الكتب في قاعدة البيانات

## المشكلة
كتاب "أهم 6000 جملة في الإنجليزي" موجود فعلياً في المخزون لكن البحث فشل في إيجاده بسبب اختلاف صيغ الكلمة (الانجليزيه vs الإنجليزي).

## الحل المطبق
تم تطبيق نظام تطبيع نصي عربي (Arabic Text Normalization) يعالج:
- توحيد أشكال الألف (أ، إ، آ → ا)
- توحيد التاء المربوطة والهاء (ة → ه)
- إزالة التشكيل
- توحيد الياء والألف المقصورة (ى → ي)
- توحيد همزة على و/ي (ؤ → و، ئ → ي)
- المطابقة بين المفرد والجمع (لغة ↔ لغات)

## كيفية التحقق من الكتب يدوياً

### 1. التحقق من كتاب "أهم 6000 جملة في الإنجليزي"

```javascript
// في MongoDB shell أو عبر Node.js
db.products.findOne({
  product_name: { $regex: "6000 جملة", $options: "i" }
})
```

**البيانات المتوقعة:**
- `products_id`: (المعرف الفعلي)
- `product_name`: "أهم 6000 جملة في الإنجليزي"
- `product_category`: "لغات"
- `product_description`: "دليل عملي لتعلّم التحدث باللغة الإنجليزية بطلاقة..."
- `product_quantity`: 200
- `keywords`: ["انجليزي", "انجليزية", "تعلم", "لغة", "محادثة", "جمل", "كلمات"]

**ما يجب التحقق منه:**
1. هل التصنيف هو "لغات"؟
2. هل الوصف يحتوي على كلمات مفتاحية مرتبطة باللغة الإنجليزية؟
3. هل حقل `keywords` يحتوي على صيغ مختلفة من "إنجليزي"؟

### 2. التحقق من كتاب "اكتب حتي لا اصاب بالجنون"

```javascript
db.products.findOne({
  products_id: "427502239565"
})
```

**ما يجب التحقق منه:**
1. هل الكلمات المفتاحية عامة بشكل مفرط؟
2. هل التصنيف دقيق لمحتوى الكتاب؟
3. هل الوصف يحتوي على كلمات عامة تجعله يطابق أي بحث؟

**الكلمات المفتاحية المتوقعة (إذا كانت عامة):**
- "كتابة"، "تطوير"، "نفسي" (بدون سياق كافٍ)

**الكلمات المفتاحية الموصى بها:**
- "كتابة إبداعية"، "تطوير الذات"، "الصحة النفسية"، "الإبداع"، "التعبير عن الذات"

### 3. اختبار سيناريو البحث الفعلي

```javascript
// في Backend
const BookSearchService = require('./services/book-search.service');

async function testSearch() {
  const result = await BookSearchService.searchBooks(
    'محتاج كتاب ليعلمني اللغه الانجليزيه',
    { limit: 10, useRecommendationEngine: true }
  );
  
  console.log('Books found:', result.books.length);
  console.log('Books:', result.books.map(b => ({
    id: b.products_id,
    name: b.product_name,
    category: b.product_category
  })));
}
```

**النتيجة المتوقعة بعد الإصلاح:**
- يجب أن يظهر كتاب "أهم 6000 جملة في الإنجليزي" في النتائج
- يجب أن لا يظهر كتاب "اكتب حتي لا اصاب بالجنون" في النتائج

