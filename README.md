# نظام إدارة محلات بيع وتأجير بدل العرائس
## Suit Store Management System

نظام سطح مكتب متكامل واحترافي مصمم خصيصًا لإدارة محلات بيع وتأجير بدل العرائس، ومخازن الأحذية والإضافات الرجالية، وإدارة الحجوزات والمبيعات والعمليات المالية والتقارير.

---

### المواصفات التقنية والمعمارية
- **نظام التشغيل المستهدف:** Windows Desktop (Offline-First)
- **الواجهة الأمامية (Renderer):** Angular Standalone Components (TypeScript)
- **بيئة سطح المكتب:** Electron (Isolated Context & Preload Security)
- **محرك المنطق الخلفي:** Node.js داخل Electron Main Process
- **قاعدة البيانات:** SQLite (ACID Transactions, Foreign Keys, Migrations)
- **اللغة والاتجاه:** اللغة العربية (RTL Support)
- **العملة الأساسية:** الجنيه المصري (EGP)
