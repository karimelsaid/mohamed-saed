# وثيقة متطلبات المنتج (Product Requirements Document - PRD)
**المشروع:** Suit Store Management System  
**الإصدار المستهدف:** 1.0 (MVP+ Ready)

## 1. المستخدمون والأدوار
- **المستخدم الحالي:** مالك المحل (Owner Account) مع صلاحيات إدارة كاملة وقفل سريع برقم سري (PIN/Password).
- **التصميم المستقبلي:** المعمارية مجهزة لاستيعاب موظفين وصلاحيات متعددة دون إعادة بناء.

## 2. النطاق الوظيفي الأساسي
1. **المخزون الثنائي:** مخزون كمي (Quantity Inventory) للأحذية والإكسسوارات، ومخزون فردي برقم باركود فريد (Individual Units) للبدل والقطع المؤجرة.
2. **محرك الحجوزات والتأجير:** فحص التوفر بالدقيقة واليوم، منع الازدواجية، دورة حياة كاملة (حجز، بروفة، تجهيز، تسليم، إرجاع، فحص، غسيل، تسوية).
3. **نقطة البيع (POS):** مبيعات مباشرة فورية للقطع الكمية والبدل المخصصة للبيع مع فواتير فورية.
4. **المحرك المالي والصندوق:** تسجيل المقبوضات والمصروفات، فتح وإغلاق جلسات الخزينة اليومية، وتتبع العجز والزيادة.
5. **الفواتير والطباعة:** طباعة A4 وطباعة إيصالات حرارية 80mm متوافقة تمامًا مع اللغة العربية.
6. **النسخ الاحتياطي والتحديثات:** نسخ محلي وسحابي، وتحديثات تلقائية لا تمس قاعدة بيانات العميل.
