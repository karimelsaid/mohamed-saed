# الأمان والحماية (Security Architecture)
- **عزل الواجهة:** منع `nodeIntegration` وتفعيل `contextIsolation` لضمان عدم وصول سكربتات الواجهة لنظام الملفات مباشرة.
- **التحقق الصارم من المدخلات (Input Validation):** فحص جميع البيانات القادمة عبر IPC باستخدام DTOs وSchemas دقيقة.
- **حماية قاعدة البيانات:** الاعتماد التام على Prepared Statements المشفرة لمنع SQL Injection نهائيًا.
- **تشفير النسخ الاحتياطية:** دعم تشفير النسخ الاحتياطية بكلمة مرور قبل رفعها إلى Google Drive أو حفظها محليًا.
