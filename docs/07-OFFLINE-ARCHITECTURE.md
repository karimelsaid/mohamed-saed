# معمارية العمل دون إنترنت (Offline-First Architecture)
- يعمل النظام بنسبة 100% بكافة إمكانياته دون الحاجة لأي اتصال بالشبكة.
- جميع العمليات والبيانات والتقارير مخزنة محليًا داخل SQLite على جهاز المستخدم.
- خدمات الإنترنت اختيارية وإضافية فقط: النسخ الاحتياطي على Google Drive، روابط المراسلة السريعة عبر WhatsApp Web/Desktop، وفحص التحديثات.
