# نظام التحديثات التلقائية (Update System)
- فحص آمن للتحديثات عبر سيرفر متوافق (GitHub Releases / Custom Server).
- أخذ نسخة احتياطية محلية تلقائية من قاعدة البيانات قبل تطبيق أي تحديث.
- تطبيق المهاجرات (Database Migrations) بشكل تلقائي وتدريجي عند إقلاع الإصدار الجديد مع فحص سلامة البيانات.
- في حال فشل التحديث أو فشل الترحيل، يعود النظام تلقائيًا للنسخة المستقرة السابقة دون أي فقد للملفات.
