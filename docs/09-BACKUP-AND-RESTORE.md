# محرك النسخ الاحتياطي والاستعادة (Backup & Recovery)
- **نسخ احتياطي محلي:** بضغطة زر أو دوري عند إغلاق التطبيق داخل مجلد آمن يختاره المستخدم.
- **نسخ سحابي:** تكامل مع Google Drive API لرفع ملف النسخة المشفر تلقائيًا.
- **التحقق من السلامة:** فحص ملف النسخة الاحتياطية ومطابقة HASH قبل اعتماده.
- **أداة الاستعادة المستقلة (Recovery Tool):** أداة برمجية منفصلة تسمح باستعادة البيانات حتى في حال تعطل واجهة البرنامج الرئيسية.
