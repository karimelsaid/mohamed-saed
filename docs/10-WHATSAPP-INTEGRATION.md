# تكامل واتساب (WhatsApp Integration)
- **طريقة العمل في الإصدار الأول:** الاعتماد على بروتوكول `Click-to-Chat` لفتح محادثة واتساب الرسمية مع العميل برقم هاتفه المصري المصحح تلقائيًا (+20).
- **قوالب الرسائل الجاهزة:**
  - تأكيد الحجز وموعد البروفة.
  - تذكير بموعد استلام البدلة.
  - تنبيه بموعد إرجاع البدلة وتجنب الغرامات.
  - إيصال الفاتورة وشكر العميل.
- معمارية النظام مجهزة للترقية إلى WhatsApp Business Cloud API عند توفر اشتراك رسمي.
