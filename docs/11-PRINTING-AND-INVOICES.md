# محرك الطباعة والفواتير (Printing Engine)
- **نماذج الطباعة:**
  1. فاتورة / عقد تأجير A4 مفصل يحتوي على الشروط والأحكام ومواصفات البدلة وقيمة التأمين.
  2. إيصال استلام ودفع حراري مقاس 80mm سريع وموجز لنقاط البيع.
- **الدعم العربي الكامل:** استخدام معايير طباعة متقدمة تضمن وضوح الخط العربي وعدم تداخل الحروف أو تشوهها.
- **إعدادات الطابعة:** حفظ الطابعة الافتراضية لكل نوع (حراري / A4) مع خيار المعاينة قبل الطباعة.
