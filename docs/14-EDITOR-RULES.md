# قواعد وأعراف التطوير (Coding & Architecture Rules)
- كتابة تعليقات واضحة وشرح معماري لكل خدمة.
- استخدام Strict TypeScript دون السماح بـ `any` إلا للضرورات الموثقة.
- إحاطة جميع العمليات المالية والمخزنية بـ Transactions محكمة.
- التحقق المزدوج من المدخلات في الواجهة وفي Electron Services.
- توثيق التقدم فورًا في `docs/EXECUTION-STATUS.md` بعد كل خطوة واختبار.
