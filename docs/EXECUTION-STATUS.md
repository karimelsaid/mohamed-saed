## 5. القرارات المعمارية (Architectural Decisions)

1. **ADR-001 (Database Adapter Pattern):** اعتماد محرك SQLite المدمج عالي الأداء مع معايير الـ ACID transactions.
2. **ADR-002 (Strict IPC Sandboxing):** حصر استدعاءات الواجهة في قناة موحدة بقائمة بيضاء.
3. **ADR-003 (Sequential Execution & Quality Gates):** الالتزام الصارم بتنفيذ المراحل بالتتابع واختبار كل مرحلة قبل الانتقال لما بعدها.
4. **ADR-006 (Zero Double-Booking Engine):** فحص التوفر الذري لحجوزات البدل الفردية داخل Transaction مغلقة.
5. **ADR-007 (Reusable Design System):** بناء كافة عناصر الواجهة كمكونات قابلة لإعادة الاستخدام.
6. **ADR-008 (Centralized Store & Policy Configuration):** حفظ سياسات التأجير في جدول `settings` بمفاتيح موحدة.
7. **ADR-009 (Dual Inventory with Strict Ledger):** الفصل التام بين المخزون الفردي المرقم بباركود فريد للبدل، والمخزون الكمي للأحذية والإكسسوارات، مع فرض قاعدة **استحالة الرصيد بالسالب** وحفظ كل حركة بسجل غير قابل للتعديل.
8. **ADR-010 (Nested Transactions via SQLite Savepoints):** دعم تداخل المعاملات باستخدام SAVEPOINTs في `TransactionHelper` لتفادي أخطاء SQLite عند استدعاء خدمات فرعية داخل معاملات كبرى.
